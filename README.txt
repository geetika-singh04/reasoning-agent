AI Assignment – Classical Reasoning Agent
=========================================

----------------

The submission contains the following files:

3. DATASETS
-----------

The reasoning agent was evaluated using the following public datasets:

- RuleTaker (jise/ruletaker)
- FOLIO (yale-nlp/FOLIO)
- CounterBench (CounterBench/CounterBench)

The notebook loads the public datasets from Hugging Face. An internet connection may be required when the datasets are not already available locally.

4. HOW TO RUN
-------------

1. Open reasoning_agent.ipynb using Jupyter Notebook or JupyterLab.
2. Check the CONFIG cell and configure the private test file path when the private test dataset is made available.
3. Select Kernel → Restart & Run All.
4. Run all notebook cells in sequence.

The notebook performs the public dataset evaluations, displays accuracy and inference time, and generates the experimental report.

When a private test input is supplied through the configured path, the notebook can generate submission.csv containing the question IDs and predicted True/False labels.

5. REASONING APPROACH
---------------------

The system selects its reasoning method based on the input format.

A. English rule-based questions (RuleTaker)
   - Rule parsing and knowledge representation
   - Forward chaining
   - Backward chaining
   - Unification and rule matching

B. First-order logic questions (FOLIO)
   - First-order logic parsing
   - Negation Normal Form and CNF conversion
   - Skolemisation
   - Resolution
   - BFS, DFS, UCS, and A* search strategies

C. Causal and counterfactual questions (CounterBench)
   - Structural causal models
   - Abduction
   - Intervention
   - Prediction using forward reasoning

No generative AI model is used to produce the final predictions. The final decisions are obtained using classical reasoning techniques.
